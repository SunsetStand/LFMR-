# Phonon-cutoff convergence of fixed-frame LF-MRPT2 (four-site scans)

Block-Hamiltonian LF-MRPT2 on the archived fixed LF frames, with the
all-mode inclusive total-phonon cutoff `M` raised point by point until it
converges. These are the data behind the two redrawn SI figures
(`figures/`). Computed 2026-10-12 to 2026-10-13 on the UCI Greenplanet
Slurm cluster.

## Calculations

| Case | `nelec` | `U` | `omega` | `alpha` grid | Points |
|---|---|---|---|---|---|
| single | (1,0) | 0 | 0.5 | 0, 0.2, ..., 3.0 | 16 |
| multi | (2,2) | 4 | 0.5 and 5 | 0, 0.4, ..., 4.0 | 22 |

All runs use `L=4`, `t=-1`, and the archived frames and momentum sector from
`reference_data/{single,multi}_frames.npz`. The reference overlap cut is
`1e-10`. The external overlap cuts are `1e-8` (primary) and `1e-10`, and
arithmetic is `float64`.

For each point, `M = 1, 2, ...` was increased until the primary cut met the
historical criterion: two successive increments `|E(M) - E(M-1)| < 1e-6`.
The smallest such `M` is `M*`. All 38 points converged, with
`3 <= M* <= 14`.

The `1e-10` cut was computed at every `M` until it either converged or
failed at the latest `M`. Its failures are `float64` numerical-check
failures: retained overlap directions near the cut amplify roundoff in the
external Hamiltonian or metric. They are unrelated to the phonon cutoff.
Wherever both cuts succeed at the final `M`, they agree to within `2e-10`.

## Layout

| Path | Contents |
|---|---|
| `summary/{single,multi}_mrpt2_m_converged.csv` | One row per point: ED/MR energies, final MRPT2 energy for each cut, `M*`, status, algorithm and external rank |
| `figures/{single,multi}_mrpt2_m_converged.{png,pdf}` | Redrawn comparison figures (ED, LF-HF, LF-MP2, LF-MR, MRPT2 at both cuts) |
| `history/{single,multi}/w<omega>_a<alpha>.csv` | Every computed `(M, cut)` row, including failures and their messages |
| `history/{single,multi}/w<omega>_a<alpha>.json` | Stop reason of the **last** job for that point (see below) |
| `validation/lean_w0.5_a{1.6,2.0,2.4}.*` | Lean algorithm at `M=5-7`, for comparison with the complete-algorithm rows in `history/multi` |
| `slurm/` | Batch script, resubmission daemon, validation job and summary helper, as run (absolute cluster paths) |

The history CSVs are authoritative. The summary CSVs and figures are
regenerated byte for byte from them:

```bash
python -m examples.plot_mrpt2_convergence --runs results/mrpt2_phonon_cutoff_convergence/history --output-dir <dir>
```

A per-point JSON describes only its last job. For multi `omega=0.5,
alpha=2.0`, for example, that job computed only the `1e-8` cut at `M=14`.

### History columns

- **Point and model:** `case`, `omega`, `alpha`, `character`, `mr_energy`,
  `reference_cut`.
- **Space definition:** `max_total` (`M`), `nconfig` (nonvacuum phonon
  configurations), `n_candidates` (candidate columns actually built),
  `external_cut`, `precision_mode`.
- **Algorithm:** `algorithm` is `full`, `reduced` or `lean`. An empty value
  means `full` (rows written before the column existed). For reduced and
  lean rows, `spin_parity`, `seed_reductions`, `complement_gram_max` and
  `cut_scale` record the symmetry reduction.
- **Results and checks:** `status` (`ok`/`failed`), `failure`, and the
  solver fields `reference_energy`, `second_order_energy`,
  `corrected_energy`, `reference_gap`, `minimum_denominator`,
  `reference_residual`, `response_residual`, `first_order_norm_squared`,
  `reference_rank`, `external_rank`, and the three metric errors.
- **Cost:** `build_seconds`, `solve_seconds`, `peak_gib` (process peak
  resident memory).

When a failed `(M, cut)` was recomputed, both rows are kept. The convergence
test uses only successful rows.

## Algorithms

Code is on branch `claude/mrpt2-4sites-alpha-scan-28790f` (commit
`a8e693e`). It comprises `examples/mrpt2_m_convergence.py`,
`examples/plot_mrpt2_convergence.py` and `mr_lf/mr/reduced.py`.

- **`full`:** the complete projected candidate list, as in `LFMRPT2`.
- **`reduced` / `lean`:** exact translation-orbit collapse of the
  translation-invariant CS seed, plus the spin-exchange sector of the MR
  root for the other seed. The external cut threshold keeps the
  complete-list scale. `lean` also stores Gram matrices per electronic
  group.
- **`--defer-h`:** used only for multi `omega=0.5, alpha=2.0, M=14` (42 GiB
  peak). It contracts `H_TT` one group pair at a time.

At `M<=7`, the reduced and lean energies match `full` to `<=6e-14` for the
`1e-8` cut. They also reproduce the archived `M<=5` values. Pass/fail of the
`1e-10` cut can differ between algorithms at points sitting on the
conditioning edge.

### Run-specific notes

- **multi `omega=0.5, alpha=2.4`, `M=12`:** the solve first failed with
  LAPACK "Eigenvalues did not converge". It was recomputed after adding an
  eigensolver fallback (SciPy `evr`, then `ev`), with the acceptance checks
  unchanged. Both rows are in the history.
- **ω=5, α=0.4–2.0:** these points ran entirely with `full`.

## Environment

Python 3.12.12, NumPy 2.2.6, SciPy 1.16.3, PySCF 2.14.0, Matplotlib 3.11.2,
OpenBLAS threads per job. The pinned NumPy 2.5.3/SciPy 1.18.1 have no wheels
for the cluster's glibc 2.17. Archived MRPT2 energies were reproduced to
roundoff in this environment.
