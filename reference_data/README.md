# Compact reference results

**Chenxi Wang & Zhihao Cui (advisor)**

These files retain the main numerical results from the research workspace.
They permit immediate plotting without repeating expensive calculations.
They do not contain unit tests, historical executables, worker logs, raw
Hamiltonian blocks or unfinished high-phonon-cutoff batches.

## Fixed physical parameters

All data use L=4, t=-1, alpha=g^2/omega, uncentered physical energy and no
phonon zero-point constant. Single electron: nelec=(1,0), U=0, omega=0.5,
alpha=0,0.2,...,3. Multiple electrons: nelec=(2,2), U=4, omega=0.5 and 5,
alpha=0,0.4,...,4. Stored centered ED solves carry explicit uncentered energy
shifts and independent residual/cutoff evidence.

Single-electron MR uses the complete translation families of the best LF-HF
and CS-start LF-HF seeds. The corresponding projected PT reference uses
character +1. Single-electron PT2 data use the successful fixed Q-overlap cut
1e-8 recipe, reference cut 1e-10 and original float64 arithmetic, with each
point's actual M recorded. They are not a new per-point cutoff optimization.

Multi-electron MR/PT2 seeds are the selected LF-HF frame and a uniform CS
frame (lambda=0, z_x=-g*N_e/(L*omega)). Both retain full site CI. The chosen
q=0 or pi sector is recorded per point. M5 uses all 125 nonvacuum phonon
configurations, reference cut 1e-10, external cut 1e-8 and
`reconditioned_longdouble` arithmetic. The supplied frame arrays are
extracted directly from the archived M5 input files.

The primary multi-electron comparison uses the all-mode M12 LF-MP2 reference
recorded with the MRPT2 data. Its mode restriction is recorded as four.
The API also allows the original two-excited-mode single-reference recipe.

## What the flags establish

- `ed_solver_converged` checks the numerical truncated ED solve;
  `ed_cutoff_converged` refers to archived oscillator convergence evidence.
- `numerically_valid` checks PT2 equations, metrics and spectral constraints.
- `phonon_converged` / `phonon_convergence_established` refer to different
  explicitly recorded cutoff studies; numerical success alone is insufficient.
- Historical single-electron `converged` combines phonon and independent
  overlap-cut checks. In the merged figure table this is `mrpt2_converged`.
- Multi-electron M5 has **no established phonon convergence**. Its merged
  `mrpt2_converged` and `mrpt2_phonon_converged` are false. Historical M3/M4
  overlap studies do not imply overlap stability at M5.
- The MR frame study improves a finite chosen candidate pool; it leaves a
  gap to ED and is not labeled an exact-limit extrapolation.

Density columns in the merged historical tables preserve the original
unprojected MR measurements. Their lowest energies agree with the selected
projected reference within the archived checks. Near-degenerate MR roots
retain their ambiguity flags; plots mark those points separately. The
symmetry example independently computes both orbit and projected densities
from the supplied frames.

`multi_cs.csv` contains new multistart unrestricted CS calculations, with
AFM, CDW, hopping-eigenvector and warm-start candidates. Every chosen state
passes the separate orbital stationarity check; `cs_optimizer_success`
records BFGS termination independently. CS-MP2 includes both one-phonon
singles and opposite-spin Hubbard doubles.
